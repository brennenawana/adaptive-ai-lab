STEP 9 -- strict type + unit-band filter: ADVISORY AT INGEST, NOT A DROP
------------------------------------------------------------------------------
crexi_ingest.py:386-389 computes `strict` and uses it for exactly two things:
the strict_matches counter, and whether to mirror photos. The row is appended
to `rows` and upserted REGARDLESS. The module docstring says so outright:
  "The full strict filter set (2-4u etc.) is NOT applied here -- the ingest
   stores the configured-type superset so the downstream valuation/routing
   pass owns deal qualification and unknown-unit listings aren't lost."
So a non-strict asset is STORED. The unit band drops it downstream, in the
value route's qualification step -- a different stage with a different fix.
