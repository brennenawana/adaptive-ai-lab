# Pattern Index\n\n- [multi-criteria-lookup-sumproduct](wiki/patterns/multi-criteria-lookup-sumproduct.md): VLOOKUP fails on multiple match columns; use SUMPRODUCT with multiple IF conditions to match two criteria columns and return value.\n\n- [conditional-vertical-lookup-array-formula](wiki/patterns/conditional-vertical-lookup-array-formula.md): Need to lookup values that meet a condition (e.g., start with 'PK') without manual filtering; use INDEX/SMALL/IF array formula with ROW() to get nth matching value, entered with Ctrl+Shift+Enter.\n\n- [type-conversion-time-extraction](wiki/patterns/type-conversion-time-extraction.md): RIGHT() function returns time as text string, preventing AM/PM formatting from working; use MOD(datetime,1) to extract time as numeric value, then apply time format h:mm:ss AM/PM.\n\n- [delimiter-separated-field-parsing](wiki/patterns/delimiter-separated-field-parsing.md): Excel formulas struggle with conditional processing of delimited fields; parse in code by splitting on delimiter, applying filter conditions (prefix checks, etc.), then aggregating results.\n\n- [unique-value-deduplication-sorted](wiki/patterns/unique-value-deduplication-sorted.md): Multiple items map to multiple categories; use set/collection to gather unique values, then sort alphabetically/numerically to avoid duplicate results.\n\n- [nested-error-handling-priority](wiki/patterns/nested-error-handling-priority.md): Need first non-#N/A value from multiple columns in priority order; nest IFERROR functions: =IFERROR(A, IFERROR(B, IFERROR(C, \"\")))\n\n- [sequential-column-extraction](wiki/patterns/sequential-column-extraction.md): Extract filtered data from multiple columns (e.g., integers from A, skip column B decimals, integers from C); process each source column completely before moving to next, then arrange output.\n\n- [dynamic-column-search-and-relocation](wiki/patterns/dynamic-column-search-and-relocation.md): Column position changes daily; dynamically find column by header name and move to target column with formatting preserved.\n\n- [date-threshold-filtering](wiki/patterns/date-threshold-filtering.md): Extract rows where date is older than N days from maximum date; find max date, calculate threshold date (max - N days), filter rows < threshold, copy to new sheet with header.\n\n- [date-window-aggregation](wiki/patterns/date-window-aggregation.md): Calculate rolling average or sum over dynamic time windows (e.g., previous 365 days) for sparse date data; use date arithmetic to find window boundaries and iterate through matching records.\n\n- [conditional-aggregation-sumproduct](wiki/patterns/conditional-aggregation-sumproduct.md): Calculate dynamic sums based on multiple criteria (e.g., total area by material type); use SUMPRODUCT to multiply condition arrays with data ranges: =SUMPRODUCT((condition1)*(condition2)*(data_column1)*(data_column2)).\n\n- [text-numeric-range-parsing](wiki/patterns/text-numeric-range-parsing.md): Parse text-formatted numeric ranges like \"2 to 5\" to extract start/end values and calculate inclusive count; use regex to extract numbers, then apply arithmetic (end - start + 1) for inclusive range.\n\n- [reverse-order-row-operations](wiki/patterns/reverse-order-row-operations.md): Bulk delete or insert rows can shift row numbers, causing formulas to reference wrong rows; process rows from highest number to lowest to maintain stable row references.\n\n- [consecutive-occurrence-counting](wiki/patterns/consecutive-occurrence-counting.md): Count consecutive rows matching a criterion and display count only on final row of each group; look ahead to detect group boundary, count backward when boundary found, write count only on last row.\n\n- [lookup-table-population](wiki/patterns/lookup-table-population.md): Populate multiple output columns based on a lookup key (e.g., cycle day determines all classes); build reference table from source data, then query it to fill multiple columns for each target row.
