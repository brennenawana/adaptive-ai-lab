# Pattern Index

- [contradicting-provided-examples](wiki/patterns/contradicting-provided-examples.md): Tasks score 0 even with literal values written, because the agent invents its own interpretation of ambiguous business logic and ignores the worked examples already present in the file (pre-filled "Expected Result" cells) or stated in the prompt. Fix: extract every given example first, treat it as a unit test, and iterate on the rule until 100% of *non-blank* examples reproduce before writing anything (trailing blanks usually mean "not yet computed", not "must stay empty").
- [dropped-dimension-in-rule](wiki/patterns/dropped-dimension-in-rule.md): Rule scores 0 because it silently ignores an input column/axis the prompt explicitly names (6239 dropped "Variance to Goal", 194-19 dropped the Tab/position axis) — and the quoted examples fail to catch it since they all share one value of the missing dimension. Fix: list every input the prompt names, assert each is read by your code, and prefer examples that differ along each axis before trusting a match.
- [partially-completed-region-is-the-spec](wiki/patterns/partially-completed-region-is-the-spec.md): "I've completed results for the first meet / here's a sample sheet" means part of the answer is already in the file; agents that ignore it invent a rule and overwrite the ground truth (194-19 failed twice this way). Fix: reverse-engineer the rule from the completed region, assert your code reproduces it cell-for-cell, then extend to the empty region and never rewrite the completed one.
- [multi-requirement-instruction-checklist](wiki/patterns/multi-requirement-instruction-checklist.md): Prompts often bundle formatting imperatives (bold/border headers, wrap text, "no values or bordering on column G") with the computation; ignoring any one of them scores 0 even when the numbers are right. Fix: split the prompt into one checklist item per imperative sentence, implement each, and print a per-item verification (58484 flipped 0.0 -> 1.0 exactly this way).
- [misread-lookup-table-geometry](wiki/patterns/misread-lookup-table-geometry.md): Agent treats a helper block as two independent payout tables and invents interpolation ("goal + metric − base"), or indexes the payout grid by the wrong axis, when in fact one table holds *bucket thresholds* (its header row = the other dimension's boundaries) and the second table is the payout grid. Fix: read a helper table's first row/column as boundaries, index rows/cols instead of summing, and confirm which axis each grid dimension belongs to.
- [row-restructure-breaks-references](wiki/patterns/row-restructure-breaks-references.md): insert_rows/delete_rows or rewriting a sheet row-by-row scores 0 because openpyxl does not translate formula references, does not carry styles/merges into new rows, and silently drops values (empty strings become None) on the shifted rows. Fix: regenerate each moved formula for its new row number (or write its literal value), copy styles explicitly, and diff the reloaded output against the input row-by-row.
- [destructive-overwrite-of-given-content](wiki/patterns/destructive-overwrite-of-given-content.md): Agent overwrites pre-filled sample answers, replaces existing formulas with literals, or blanks whole columns "to satisfy" the instruction, destroying cells the grader compares. Fix: only write cells that are genuinely empty/targeted; never convert someone else's formulas to values; re-diff output vs input and justify every changed cell.
- [ignore-reference-and-sheet-structure](wiki/patterns/ignore-reference-and-sheet-structure.md): Agent lists/dumps the extra sheet but never *uses* it, even when that sheet literally contains the expected output ordering (22-47's `ورقة1`), and edits the first/guessed sheet instead. Fix: dump every sheet, diff before/after or sample sheets to derive the transformation, and validate your output against them (note: the promised demo sheet is sometimes absent — then the prompt's row-by-row narrative is the spec).
- [formula-written-but-no-cached-value](wiki/patterns/formula-written-but-no-cached-value.md): Tasks score 0 when the agent writes Excel formula strings via openpyxl, because openpyxl never evaluates formulas so the saved cells have no cached value and graders reading values see None/empty. Fix: compute the answer in Python and write the literal value — even when the user literally asks "fix my formula / how do I copy this formula across" (LibreOffice `soffice` is NOT installed — exit 127).
- [ignored-none-verification-signal](wiki/patterns/ignored-none-verification-signal.md): Agent "verifies" by simulating the formula in its head or by re-reading the formula string instead of the computed value, sees None/nothing, and still declares success — sometimes with a buggy print loop that hides the missing cell. Fix: reload with `data_only=True` and assert the target cells hold non-None literal values; never accept a narrated evaluation as verification.
- [dynamic-array-spill-formula-misuse](wiki/patterns/dynamic-array-spill-formula-misuse.md): Using spill functions (FILTER, SORT, UNIQUE) in one cell leaves every other expected result cell empty in the saved file since openpyxl/graders don't spill. Fix: materialize the full result list into each target cell explicitly.
- [compute-values-in-python-success](wiki/patterns/compute-values-in-python-success.md): All scoring runs succeeded by doing the transformation in Python (dump every sheet, locate headers dynamically, build a dict lookup, write literals) AND anchoring the rule to given ground truth (pre-filled cells, numbers quoted in the prompt) before saving. Fix: deterministic Python transformation + assert against every stated/known expected value, and prefer the prompt's concrete row-by-row examples over its abstract summary when they conflict.
