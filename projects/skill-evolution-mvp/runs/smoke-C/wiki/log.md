## [iter 1] Iteration 1 (2 tasks): 141-20 scored 1.000, 57445 scored 0.000. Root cause of the failure was not the lookup logic (it was semantically right) but that openpyxl-written formulas carry no cached values AND the formula was a CSE array formula that never evaluates outside Excel — grader read empty/None cells. Also observed a recurring environment trap: pandas in the project .venv sees openpyxl 3.1.3 while pip upgrades the user site-packages, so `pip install --upgrade openpyxl` loops forever; the successful task escaped by dropping pandas and using openpyxl directly. Created 4 patterns: excel-formula-needs-cached-values, avoid-cse-array-formulas, pandas-openpyxl-version-mismatch, inplace-workbook-edit-preserves-structure.
