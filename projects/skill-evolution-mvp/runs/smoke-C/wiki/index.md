> # Pattern Index

- [excel-formula-needs-cached-values](wiki/patterns/excel-formula-needs-cached-values.md): Writing formulas with openpyxl saves only formula strings with no cached `<v>` results, so value-based graders read None and score 0 (confirmed twice, even with a semantically correct SUMIFS); fix by recalculating the saved file headlessly (`soffice --headless --convert-to xlsx`) or by also writing computed literal values, then verifying with `data_only=True`.
- [fake-verification-hardcoded-expectations](wiki/patterns/fake-verification-hardcoded-expectations.md): Agent "verifies" by printing a hardcoded expected-value table (or by re-reading formula strings) instead of the actual computed cell values, so a 0-score output looks verified; fix — verification must read the *saved* file with `data_only=True` and assert the real numbers, never print literals the script already knows.
- [avoid-cse-array-formulas](wiki/patterns/avoid-cse-array-formulas.md): Multi-criteria lookups written as `INDEX/MATCH(1,(A=x)*(B<=y),0)` need Ctrl+Shift+Enter and silently fail outside Excel; use SUMIFS/SUMPRODUCT/LOOKUP with bounded ranges (`$A$2:$A$19`, not `$A:$A`) — but note SUMIFS alone is not enough without recalculation.
- [pandas-openpyxl-version-mismatch](wiki/patterns/pandas-openpyxl-version-mismatch.md): `pd.read_excel` raises "Pandas requires version '3.1.5' or newer of 'openpyxl'" because pip upgrades the user site-packages, not the active .venv; don't fight pip — switch to direct `openpyxl.load_workbook`, which also preserves formatting.
- [inplace-workbook-edit-preserves-structure](wiki/patterns/inplace-workbook-edit-preserves-structure.md): Success pattern — load the workbook with openpyxl, mutate cells / `delete_rows` in reverse index order, save, then re-open the saved file and print every sheet to verify; rewriting via pandas ExcelWriter loses formatting and extra sheets.
